# InformantTGBot — Бизнес‑ассистент для Telegram

Асинхронный Telegram‑бот с локальным ИИ (Ollama), распознаванием речи (Whisper), скачиванием видео/аудио, мемами, RP действиями, режимом «отошёл», сохранением ссылок, **токенной экономикой** и **платными командами** (опционально).

```bash
git clone https://github.com/Lonewolf239/InformantTGBot.git
cd InformantTGBot
pip install -r requirements.txt
cp dotenv_template .env
python -m bot.main
```

### Дополнительные требования (вне Python‑пакетов)

- **Ollama** – установить с [ollama.ai](https://ollama.ai), скачать модель: `ollama pull qwen2.5:3b` (при необходимости изменить в `config.py`).
- **Whisper** – при первом использовании автоматически загрузит модель `base` (~1 ГБ ОЗУ).
- **FFmpeg** – необходим для обработки аудио/видео (озвучка, замена дорожки).
- **Edge‑TTS** – используется для синтеза речи; работает без дополнительных ключей.
- **cookies.txt** – поместите файл с cookies в формате Netscape в корневую папку бота для обхода ограничений YouTube (ошибки 403, контент 18+).

## Базы данных

- `bot_stats.db` — глобальная статистика, пользователи, история команд
- `bot_links.db` — сохранённые URL (тип, отправитель, просмотрено)
- `user_settings.db` — NSFW настройки
- `bot_tokens.db` — балансы токенов пользователей
- `owner_settings.db` — переключаемые владельцем настройки (платежи, автоответ, обратная связь двойника и т.п.)
- `twin.db` — данные цифрового двойника (база знаний, примеры диалогов, контакты, история промптов)

## Примечания

- Ежедневный лимит токенов обновляется каждую полночь (`DEFAULT_DAILY_TOKENS = 50`).
- Команды стоят токены (см. `!прайс`). VIP‑пользователи (включая владельца) ничего не тратят.
- Платежи через ЮKassa опциональны и включаются/выключаются владельцем в рантайме через меню `!настройки`, а не флагом в `config.py`.
- Бот может работать через long polling (по умолчанию) или через вебхуки (установите `USE_WEBHOOKS = True` для приёма уведомлений от ЮKassa).
- Для бизнес‑аккаунтов бот обрабатывает события `business_message` и `business_connection`.
