# InformantTGBot — Бизнес‑ассистент для Telegram

Асинхронный Telegram‑бот с локальным ИИ (Ollama), распознаванием речи (Whisper), скачиванием видео/аудио, мемами, RP действиями, режимом «отошёл», сохранением ссылок, **токенной экономикой** и **платными командами** (опционально).

```bash
git clone https://github.com/Lonewolf239/InformantTGBot.git
cd InformantTGBot
pip install -r requirements.txt
cp dotenv_template .env
python main.py
```

## Команды

### Владельца (`!ownerhelp`)
- `!отошёл`, `!вернулся`
- `!статус` – текущее состояние режима
- `!статистика` – детальная статистика бота
- `!ждущие` – список пользователей, писавших во время отсутствия
- `!сброс_таймеров` – сбросить флаги автоответа для всех
- `!очистить_статус <id>` – сбросить флаг автоответа для конкретного пользователя
- `!ссылки` – просмотр сохранённых ссылок (инлайн‑меню)
- `!линкстат` – статистика по ссылкам
- `!nsfw` – общая статистика NSFW‑настроек

### Публичные (`!помощь`)
- `!помощь` – это меню
- `!старт` – приветственное сообщение
- `!анекдот` – случайная шутка
- `!мем` – случайный мем
- `!погода [город]` – погода
- `!ии [вопрос]` – спросить локальную нейросеть
- `!нейрохам [вопрос]` – получить хамский, оскорбительный ответ (осторожно, экспериментально)
- `!расшифровка` (ответ на голосовое/видео/аудио) – распознавание речи
- `!перевести` (ответ на иностранное медиа) – перевод и новая озвучка
- `!скачать [ссылка] [опции]` – скачать видео/аудио (YouTube/TikTok/другие)
- `!музыка` / `!трек [запрос]` – поиск и скачивание музыки
- `!курс [сумма] [из] [в]` – конвертер валют (пример: `!курс 100 usd rub`)
- `!прайс` / `!цены` – показать стоимость команд в токенах
- `!баланс` – проверить баланс токенов и пополнить (если включены платежи)
- `!рп` – список RP‑команд
- `!настройки` – включение/отключение NSFW
- `!о_боте` – информация о боте
- `!donut` – поддержать разработчика
- `!алиасы` – список синонимов команд
- `!рулетка [ставка]` – сыграть в рулетку (ставка в токенах)
- `!дуэль [ставка]` – вызвать другого пользователя на дуэль (токены)
- `!кино [название]` – информация о фильме с Кинопоиска
- `!qr [текст]` – сгенерировать QR‑код
- `!кот` – случайный котик
- `!факт` – случайный факт
- `!вики [запрос]` – поиск в Википедии
- `!озвучка [текст]` – озвучить текст голосом
- `!картинка [запрос]` – поиск картинок
- `!прогноз` – случайный прогноз на день
- `!цитата` – случайная цитата
- `!курс_крипты` – курсы топ‑криптовалют в $

**RP‑команды** (ответ на сообщение):
SFW: `!обнять`, `!поцеловать`, `!ударить`, `!шлепнуть`, `!укусить`, `!погладить`, `!пнуть`, `!толкнуть`, `!ущипнуть`, `!прижать_к_стене`, `!ткнуть_по_носику`, `!лизнуть`, `!задушить`.
При включённом NSFW добавляются: `!отсосать`, `!выебать`, `!трахнуть`, `!кончить`, `!раздеть`, `!оттрахать`, `!поставить_на_колени`, `!схватить_за_член`, `!схватить_за_жопу`, `!отлизать`.

**Опции для плейлистов** (`!скачать`):
- `-random` – случайный порядок (или один случайный трек, если без числа)
- `-N` – скачать N треков (например `-5`)
- `-от_N` – начать с трека N
- `-до_N` – закончить на треке N  
Пример: `!скачать URL -random -3` – три случайных трека.

**Алиасы** – у многих команд есть синонимы (например `!help` = `!помощь`, `!ai` = `!ии`). Полный список даёт команда `!алиасы`.

**Простые ответы и реакции на ключевые слова** – бот отвечает на фразы вроде «как дела» → «норм», «пошёл нахуй» → «пошёл нахуй», а также на ключевые слова (например «партия», «Тайвань») отправляет социальный кредит или забавные аудио.

## Конфигурация (`.env`)

```ini
BOT_TOKEN=xxx
OWNER_ID=123456789
API_PID=xxx          # для анекдотов
API_KEY=xxx          # для анекдотов
MEME_API_KEY=xxx
OPENWEATHER_API_KEY=xxx
KINOPOISK_API_KEY=xxx

# Опциональные платежи (ЮKassa)
YOOKASSA_SHOP_ID=xxx
YOOKASSA_SECRET_KEY=xxx

# VIP пользователи (ID через запятую, не тратят токены)
VIP_IDS=123456,789012

# Опциональная генерация картинок (pollinations.ai)
POLLINATIONS_API_KEY=xxx
```

### Дополнительные требования (вне Python‑пакетов)
- **Ollama** – установить с [ollama.ai](https://ollama.ai), скачать модель: `ollama pull qwen2.5:3b` (при необходимости изменить в `config.py`).
- **Whisper** – при первом использовании автоматически загрузит модель `base` (~1 ГБ ОЗУ).
- **FFmpeg** – необходим для обработки аудио/видео (озвучка, замена дорожки).
- **Edge‑TTS** – используется для синтеза речи; работает без дополнительных ключей.
- **cookies.txt** – поместите файл с cookies в формате Netscape в корневую папку бота для обхода ограничений YouTube (ошибки 403, контент 18+).

## Базы данных

- `bot_stats.db` — глобальная статистика, пользователи, история команд

- `user_settings.db` — NSFW настройки
- `bot_tokens.db` — балансы токенов пользователей

## Примечания

- Ежедневный лимит токенов обновляется каждую полночь (`DEFAULT_DAILY_TOKENS = 50`).
- Команды стоят токены (см. `!прайс`). VIP‑пользователи (включая владельца) ничего не тратят.
- Платежи через ЮKassa опциональны; в `config.py` по умолчанию `PAYMENTS_ENABLED = True` (если указаны учётные данные).
- Бот может работать через long polling (по умолчанию) или через вебхуки (установите `USE_WEBHOOKS = True` для приёма уведомлений от ЮKassa).
- Для бизнес‑аккаунтов бот обрабатывает события `business_message` и `business_connection`.
